# 文本分类不同训练方法对比 — 简单总结

数据集：CLUE TNEWS，15 类中文新闻标题，train 53,360 / val 10,000。
一句话结论：**这批数据上，方法之间的差距基本都被"数据本身"卡住了，换模型收益很小。**

---

## 1. 一共跑了 13 个配置

| 方法 | 准确率 | macro F1 | 备注 |
|---|---|---|---|
| 众数基线（全猜"科技"） | 10.89% | 1.31% | 什么都不学的下限 |
| TF-IDF（词）+ SVM | 54.73% | 52.32% | |
| TF-IDF（字）+ 朴素贝叶斯 | 55.40% | 51.57% | |
| TF-IDF（字）+ 逻辑回归 | 56.38% | 53.90% | |
| **TF-IDF（字）+ SVM** | **56.37%** | 54.42% | 训练 16 秒，CPU |
| TextCNN（从零训练） | 53.35% | 50.83% | 15 epoch，GPU 约 1.5 分钟 |
| TextCNN + 加权 loss | 52.61% | 51.39% | |
| BERT 微调（cls 池化） | 56.44% | 55.14% | seed=42 重训 |
| BERT 微调（mean 池化） | 56.40% | 54.39% | |
| BERT 微调（max 池化） | 56.30% | 55.34% | |
| BERT + 加权 loss | 55.93% | 55.34% | 原项目产物 |
| LoRA SFT（5,000 条） | 58.00% | 48.65% | 只评了 200 条 |
| 零样本 Prompt | 36.00% | 28.33% | 没训练，29% 输出无法解析 |

（前 11 行都是 10,000 条全量评，最后两行是 200 条）

---

## 2. 几个比较反直觉的结论

**① 传统方法真的很强，跟 BERT 打平**

字级 TF-IDF + 线性 SVM 拿 56.37%，BERT 微调 56.44%，差 0.07pp——而前者训练 16 秒、后者 34 分钟。原因大概是新闻标题太短（平均 22 字），判别信息基本就是几个关键词，预训练那套语义理解发挥不出来。

**② "神经网络"本身不加分，预训练才加分**

TextCNN 只有 53.35%，还不如线性模型。而且它训练集准确率冲到 79%，验证集卡在 52%——5 万条数据不够从零学表示，先过拟合了。相比之下 BERT 的 1 亿参数在预训练阶段就见过大量中文，任务数据只需要"对齐标签"。

**③ 零样本能用但不敢直接用**

36%，其中 29% 是模型输出的类别不在候选集里（比如答"房地产""武器""宗教"）。它其实答得不算错，只是不用你的词表。改成"候选打分"而不是"生成"，这个失败面能直接归零。

**④ SFT 58% 不能说"超过 BERT 56%"**

它是在 200 条上评的（置信区间 ±6.8pp），BERT 是 10,000 条（±0.97pp）。更逗的是，同一批 200 条上字级 SVM 拿到 59%，比 SFT 还高——做配对检验 p=0.89，完全没区别。

**⑤ 加权 loss 只是把错误挪了个地方**

BERT 侧：证券类 recall 从 0.33 提到 0.64，但科技 −8pp、财经 −7pp，macro F1 只涨 0.35pp，总错误数没少。TextCNN 上做同样实验，结论一致。所以它解决的是"哪类不能漏"，不是"整体更准"。

---

## 3. 池化三种都试了：没差别

| 池化 | 准确率 | macro F1 |
|---|---|---|
| cls | 56.44% | 55.14% |
| mean | 56.40% | 54.39% |
| max | 56.30% | 55.34% |

极差 0.14pp，配对检验 p = 0.69 ~ 0.92，三种就是等价的。而且**光换个随机种子就差 0.26pp**（原项目 56.18% vs 我重训的 56.44%），比池化差异还大——所以池化没必要折腾，默认 cls 就行。

顺带说明：LLM 那两条路线没有池化这回事（decoder 直接出类别名），所以"三种池化 × 三条路线"这个矩阵其实只有 3 格能填。

## 4. 成本对比

| 方法 | 训练 | 单条推理 | 参数量 |
|---|---|---|---|
| TF-IDF + SVM | 16 秒（CPU） | 0.003 ms | 360 万等效权重 |
| TextCNN | 1.5 分钟（GPU） | 0.02 ms | 0.69M |
| BERT 微调 | 34 分钟（GPU） | 2.1 ms | 102M |
| LoRA SFT | 24 分钟（GPU） | 约 60 ms | 1.08M（0.22%） |
| 零样本 | 不用训 | 约 2 秒 | 0 |

效果差不多的情况下，成本能差三四个数量级。

---

## 5. 怎么选

- **没标注 → 零样本**，先跑 200 条看基线，记得加兜底；
- **几千条标注 → LoRA SFT**，5,000 条就到 58%，显存只要 3GB；
- **几万条 + 要低延迟 → 先试 TF-IDF + SVM**，十几秒训完、微秒级推理，效果和 BERT 打平；
- 不够用再上 BERT 微调，或者需要语义检索/多任务复用时才值得上大模型。

一句话：**先跑个便宜基线，别一上来就堆模型。**

---

## 6. 几个要注意的地方

- **200 条 vs 10,000 条口径不统一**：报告里凡是 LLM 的数字都是 200 条，1~2pp 的差异完全不可信；
- **验证集有泄漏**：val 里 1,099 条（10.99%）句子在训练集出现过，所以所有绝对值虚高 3~4pp，真实水平大概 52~54%；
- **类别本身重叠**：财经↔科技、国际↔军事、证券→财经这几对错得最多，四个技术路线的错误高度一致——说明是标签体系问题，不是模型问题；
- **证券类只有 45 条验证样本**，一条样本 = 2.22pp，小类指标只能定性看。

想再往上提，优先级是：修泄漏 → 合并/层级化模糊类别 → 给小类补数据 → 才是换模型。
