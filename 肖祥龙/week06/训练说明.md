- TF-IDF 已完成 2 个实验，合计耗时 0.1 分钟。
- RoBERTa 已完成 7 个实验，合计耗时 55.8 分钟，训练进程最高峰值工作集 4.47 GiB。

本机 Windows 原先把训练负载主要安排到 4 个能效核。RoBERTa Max 第一轮期间，将本批训练进程限制到 8 个性能核。此前和此后的耗时受调度条件影响。

## 模型与训练设置

- TF-IDF 使用字符 1–3 gram、`min_df=2` 和次线性词频，验证比较 `C=0.5、1、2`。
- RoBERTa 使用本地 ModelScope 中文模型 `iic/nlp_roberta_backbone_base_std`。七个方案共用 2,400 条训练文本，全参数训练 2 轮，AdamW 学习率 `2e-5`，最大长度 128。Mean 和 Max 池化屏蔽 padding。四个训练技巧分别在 CLS 上启用，使用反频率类别权重、Focal `γ=2`、FGM `ε=0.5`、标签平滑 `0.1`。
- Qwen3-0.6B 使用本地预训练权重和聊天模板，关闭思考模式，比较下一 token 的四个标签得分。Few-shot 使用固定的每类一个训练示例。三个微调方案使用相同的 512 条训练文本和标签 token 交叉熵，训练 2 轮。SFT 更新最后四层及末端归一化，LoRA 在注意力的 Q/V 投影应用 `r=8`，全量微调用 FP32、梯度检查点和无动量 SGD。
- 各系列的训练样本量及优化配置不同，分数反映本次实际运行的 CPU 实验。结果基于一次固定种子的切分和训练。

运行环境为 Windows，Python 3.12.14。模型使用的线程数、学习率、可训练参数量和轮次见各自的 `config.json` 和 `result.json`。

## 复现和预测

在项目根目录的 PowerShell 执行以下命令。

~~~powershell
python -m venv study/.venv
& 'study/.venv/Scripts/python.exe' -m pip install --index-url https://download.pytorch.org/whl/cpu torch==2.9.1+cpu
& 'study/.venv/Scripts/python.exe' -m pip install -r study/requirements.txt
& 'study/.venv/Scripts/python.exe' study/run_experiments.py --smoke
& 'study/.venv/Scripts/python.exe' study/run_experiments.py --all
& 'study/.venv/Scripts/python.exe' study/run_experiments.py --predict roberta_fgm --text "这款保温杯容量500毫升"
~~~

`--method 模型ID` 可以运行单个实验，`--all` 会复用已完成的结果。每个正式方案的产物在 `outputs/models/<模型ID>/`，包含模型或适配器、配置、逐条测试预测、各类指标与混淆矩阵。Zero-shot 和 Few-shot 复用 `model/Qwen` 权重，提示词和示例保存在各自配置中。

所有测试结果也汇总到 `outputs/results.csv`。混淆矩阵的行是真实标签，列是预测标签，顺序为电商、新闻、口语、技术。
