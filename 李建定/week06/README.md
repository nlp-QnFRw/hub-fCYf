# 第 6 周作业：数据接入与分流对比实验报告

## 📌 实验概述
本次实验基于老师提供的代码框架，将原有的新闻分类数据集**更换为《简体中文口语情感分类数据集》**，并针对 7 类情感标签（伤心、生气、关心、惊讶、开心、平静、厌恶）进行文本分类对比实验。

实验对比了规则匹配、传统机器学习（TF-IDF）以及深度学习预训练模型（原版 BERT 与 RoBERTa）在该数据集上的表现。所有实验均在相同的 755 条干净验证集上进行。

## 📂 数据集处理
- **原始数据集**：简体中文口语情感分类数据集 (共 4159 条)
- **类别数量**：7 类
- **处理流程**：读取 Excel 数据 -> 清洗标签字符 -> 映射为数字 ID -> 过滤空值 -> 8:2 划分训练集与验证集 -> 保存为标准 JSON 数组格式。

## 📊 实验结果对比

| 实验方法 | 预训练模型 / 算法 | 准确率 (Accuracy) | Macro-F1 | 训练/推理耗时 | 备注 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 方法一：规则匹配 | 关键词/规则 | 0.2291 | 0.1384 | 秒级 | 口语表达，规则泛化极差 |
| 方法二：传统机器学习 | TF-IDF + SVM | 0.8609 | 0.8564 | 0.1s | 特征工程表现优异，性价比极高 |
| **方法三：微调模型(原版)** | **BERT-base-chinese** | **0.8742** | **0.8717** | 约 24.4 ms/条 | 微调基线，表现最佳 |
| **方法四：更换预训练模型** | **RoBERTa-base** | 0.8702 | 0.8656 | 约 24.4 ms/条 | 替换为魔搭模型 |

## 💡 实验结论与分析

1. **规则方法的局限性**：
   在真实的口语情感表达中，规则方法的准确率仅为 **22.91%**。这说明简单的关键词穷举无法理解上下文和复杂语义（如反讽、多重情感），在自然语言处理任务中基本不可用。
   
2. **传统机器学习的高性价比**：
   TF-IDF + SVM 的准确率达到了 **86.09%**，仅用 0.1 秒就完成了训练和预测。这说明在短文本分类任务中，如果特征工程（n-gram）做得好，浅层模型也能取得极高的基线效果，且推理速度具备绝对优势。

3. **微调模型的最终优势与“反转”现象**：
   原版 BERT 微调后，准确率达到了最高值 **87.42%**，Macro-F1 为 **0.8717**。这证明了预训练模型强大的语义理解能力。
   **值得注意的是**：理论上更强的 RoBERTa 模型在本次实验中（87.02%）略低于原版 BERT。推测原因在于：本数据集规模较小（约 4000 条），模型表现存在随机波动；且原版 BERT 的中文预训练语料可能更契合此类口语化情感数据。这说明**“更大的模型”不一定在所有任务上都能带来正收益**，需要结合数据体量和分布进行实际测试。
