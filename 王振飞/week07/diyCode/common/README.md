# 公共数据与输出契约

`event_data.py` 提供默认数据/预训练模型路径、JSON 读取、schema、BIO 标签表、结果校验和长文本切分。可依次阅读 `schema_at → labels_for → segments → validate`。

- `schema_at` 读取事件类型与角色并跳过元信息 `__enums__`；当前校验并没有校验枚举值。
- `labels_for` 对 13 种触发词类型和 61 个去重角色分别生成 B/I 标签，加 `O` 共 149 个。
- `segments` 优先在标点附近切分并返回片段起点；片段不重叠，跨片段内容可能遗漏。
- `validate` 过滤未知类型、非法角色、无效触发词或找不到的片段，去重并记录警告。位置为全文的 Python 字符下标，左闭右开。

如果未给可靠位置，`validate` 会在原文查找片段；重复出现时选首次并提示歧义。其校验不等于语义正确。无事件时服务层追加复核提示；`needs_review` 不是校准过的模型概率。
