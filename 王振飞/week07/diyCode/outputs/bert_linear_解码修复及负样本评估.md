# BERT Linear 解码修复与检测集评估

## 方法

使用同一训练好的 `bert_linear.pt`、同一设备 CUDA 与同一 930 条 dev_extract，仅改变 BIO span 解码：相同标签的 `I-` 可跨纯空白与前一片段连接，不跨非空白，不跨不同标签。没有重新训练。修改前的逐条预测来自 `bert_linear_predictions.jsonl`；详情和样例见 `bert_linear_空白修复及检测评估.json`。

## 结果

| 指标 | 修改前 | 修改后 | 变化（百分点） |
|---|---:|---:|---:|
| 触发词 F1 | 89.86% | 89.86% | 0 |
| 论元精确率 | 63.02% | 65.99% | +2.97 |
| 论元召回率 | 74.45% | 75.81% | +1.36 |
| 论元 F1 | 68.26% | 70.56% | +2.30 |
| 完整事件 F1 | 26.19% | 27.66% | +1.47 |

论元 TP/FP/FN 从 3066/1799/1052 变为 3122/1609/996。930 条中 68 条论元集合发生变化：按每条 FP+FN 数量，65 条减少、2 条增加、1 条不变。此规则仍有副作用：一例把 `天府新区仁寿县交通基础设施PPP项目` 与后面的 `项目` 误合并；因此改进是总体结果，不是每条都变好。

## 检测集

以 `dev_detect_clean.jsonl` 的 4,815 条为测试集：只要抽出至少一个事件，就判断为“有事件”。依据数据集 has_event 标注，TP=1146、FN=21、FP=2401、TN=1247。

- 负样本误报率：2401/3648 = 65.82%。
- 有事件检测精确率：1146/3547 = 32.31%；召回率：1146/1167 = 98.20%。

这是把单事件抽取模型直接当检测器的测试，反映数据集标注口径下问题，不是人工复核后的真实线上误报率。样本包含短标题，也可能存在标注覆盖不足；需要抽样核查。

## 建议

当前应优先考虑负样本上的检测能力：以 train_detect 训练独立检测器，并使用 clean 检测集与抽取集评测端到端收益与漏报代价。先单独记录基线并做人工复核，再考虑阈值，避免规则直接过滤真实事件。CRF 可以做比较，但不能预设它能解决负样本误报。
