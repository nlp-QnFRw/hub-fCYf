1. 任务定义

先明确输出是事件还是实体，是否一句一个事件，是否需要原文位置，事件有哪些角色，没抽到事件如何返回。老师项目的核心输出是：事件类型 + 触发词 + 角色论元。

必须会：事件、触发词、论元、角色、span、schema、多事件和重叠标注。

2. 数据审计

检查 text[start:end] 是否等于标注文本；检查训练/验证重复、长尾、负样本比例、长度分布和文档 ID 是否唯一。评测键要使用 id + sent_id。

关键原则：指标可信之前，先证明数据和对齐可信。

3. 模型原理

方法解决的问题代价
规则固定触发词和格式化字段不懂复杂角色关系
BiLSTM-CRF理解序列标注与 CRF没有预训练知识
BERT+Linear主线 token 分类可能产生非法 BIO
BERT+CRF利用标签转移约束边界训练/推理更慢
LLM zero/few少标注、类型变化快格式、幻觉、成本

必学算法：BIO、token 对齐、attention mask、CRF 前向算法、维特比解码、硬约束。

4. 对比实验

固定同一数据、schema、输出格式、评测函数和随机种子。依次做规则、BiLSTM vs BERT、Linear vs CRF、max_length、层数、联合 vs 两段式、zero vs few。

同时记录 trigger F1、argument F1、event_exact、延迟、显存、训练时间、API 成本和错误样例。不要只按一个 F1 选模型。

最终最常见的工程答案不是单独押注一个模型，而是“模型抽结构 + 规则补规律字段 + 校验 + 人工复核”。

学习路线

  1. 第 1 周：读懂数据和任务，手工检查 span。
  2. 第 2 周：写规则和三级 F1。
  3. 第 3 周：掌握 BIO、BiLSTM、CRF。
  4. 第 4 周：训练 BERT Linear/CRF，做 max_length 和层数消融。
  5. 第 5 周：比较联合、两段式、LLM zero/few。
  6. 第 6 周：完成切分、校验、兜底和人工复核系统。

最终目标：你能解释每个模块为什么存在，能根据业务约束选择模型，能用公平实验说明谁更优。
