# Week03：基于 PyTorch 的 12 类语种识别

## 1. 任务描述

在课堂 8 类语种识别模型的基础上，扩展为 12 类语种识别模型。输入一段文本，预测其所属语言。

支持的语种包括：阿拉伯语（ar）、英语（en）、西班牙语（es）、印地语（hi）、日语（ja）、韩语（ko）、葡萄牙语（pt）、俄语（ru）、泰语（th）、土耳其语（tr）、越南语（vi）、中文（zh）。

## 2. 数据集与预处理

数据来自 Tatoeba 多语种句子数据集，使用课程提供的清洗版本。

| 数据集 | 样本数 | 用途 |
|---|---:|---|
| Train | 9600 | 模型训练 |
| Dev | 1200 | 训练过程验证 |
| Test | 1800 | 最终模型评估 |

文本处理流程：

1. Unicode NFKC 归一化、转小写，保留字母与组合标记。
2. 从 12 类训练集构建字符表，共 3276 个字符及特殊标记。
3. 使用字符 ID 编码文本，保留 `<PAD>=0`、`<UNK>=1`。
4. 将文本截断或填充至 40 个字符。

## 3. 模型结构

采用字符级 RNN 分类模型：

`Embedding → RNN → Masked Global MaxPool → LayerNorm → Dropout → Linear`

其中：

- Embedding 维度：64
- RNN 隐藏维度：64
- Dropout：0.3
- 输出类别：12
- 模型参数量：218892

损失函数为 CrossEntropyLoss，优化器为 Adam。

## 4. 训练参数

| 参数 | 数值 |
|---|---|
| Epochs | 8 |
| Batch Size | 64 |
| Learning Rate | 0.001 |
| Random Seed | 42 |
| CPU Threads | 1 |

训练耗时约 13 秒（本次运行环境）。

## 5. 实验结果

### 5.1 训练与验证

| Epoch | Train Loss | Dev Accuracy |
|---|---:|---:|
| 1 | 1.0338 | 91.42% |
| 2 | 0.3117 | 93.92% |
| 3 | 0.1998 | 95.42% |
| 4 | 0.1520 | 96.08% |
| 5 | 0.1322 | 96.08% |
| 6 | 0.1174 | 96.17% |
| 7 | 0.1071 | 96.33% |
| 8 | 0.0964 | 96.42% |

### 5.2 普通测试集

- Accuracy：95.33%
- Macro-F1：0.9537
- 测试集规模：1800 条

最明显的混淆出现在葡萄牙语与西班牙语之间，其中 36 条葡萄牙语被预测为西班牙语。

### 5.3 困难样本测试

| 测试类型 | 样本数 | Accuracy |
|---|---:|---:|
| 短文本（2–7 字符） | 600 | 84.5% |
| 去重音文本 | 600 | 76.3% |
| 日语去假名 | 100 | 26.0% |

困难测试表明，文本长度与语言特有字符对识别性能有明显影响。

### 5.4 混排文本测试

在 20 条手工设计的混排文本中：

- RNN 模型：18/20，90.0%
- 字符区间规则：8/20，40.0%

在完整 12 类测试集上，字符区间规则的准确率为 66.0%，低于神经网络的 95.33%。

## 6. 运行方法

安装 PyTorch 后，在项目根目录执行：

```bash
# 从训练数据生成12类字符表
python build_vocab_v12.py

# 训练模型并保存
python train_langid_v12.py --epochs 8 --save langid_rnn_v12.pt

# 普通测试集评估
python eval_langid_v12.py

# 困难样本测试
python eval_langid_v12.py --split test_hard

# 混排文本测试
python demo_mixed_text_v12.py --model langid_rnn_v12.pt --data-dir data/langid/v12
```

运行需要将课程提供的数据放置在 `data/langid/` 目录下。如果提交的仓库不包含数据文件，需要先按课程数据包恢复该目录结构。

## 7. 实验总结

本次作业完成了从 8 类到 12 类语种识别模型的扩展，实现了字符表构建、模型训练、保存及评估。

模型在常规测试集上取得 95.33% 的准确率。但在相似语种、短文本和关键字符被移除的情况下，准确率明显下降，说明字符组合与语言特有文字标记对语种识别具有重要作用。
