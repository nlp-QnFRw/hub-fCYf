`-I` 表示隔离运行，`-B` 禁止生成字节码缓存。脚本默认只显示结果，不生成文件。
若需要保存，使用本周 `outputs/` 下尚未存在的新路径：


已有结果禁止覆盖；再次保存应换一个新目录名。`--top-k 5` 控制展示候选数，默认为五个。
对照加载原始权重时，工具库会提示池化层和句间关系预测层的四个额外张量未使用；
它们不属于本次掩码预测头，原始模型没有缺失所需权重。当前课程保存模型没有这类额外项。
`--model-dir` 可显式指定本地模型目录，默认固定使用：

```text
outputs/task04_train_20261105_141502_537948/best_checkpoints/update_002500/model
```

每条文本必须恰好包含一个大写 `[MASK]`（遮盖标记），分词后长度不超过 64，包含首尾标记。
脚本拒绝其他特殊标记及无法识别的词元，拒绝超长文本，不静默截断上下文。
候选按完整词表概率排序，未过滤特殊词元；概率不重新按展示的几个候选归一化。
每个候选是一个词元，中文通常对应一个汉字；并不保证一个候选就是完整词语。
遇到以 `##` 开头的子词或特殊词元时，填入文本按原始词元字符串展示，不能当作自然语言排版结果。

## 4. 数据和遮盖目标

原始语料共 395,286 行；去除首尾空白、空行并按文本精确去重后为 246,229 条。
保留首次出现顺序后，用随机种子 42 打乱，按 95%/5% 划分成 233,917 条训练池和
12,312 条验证池。已使用的原文训练与验证样本没有精确重叠，但没有保证消除语义近重复。

正式训练取训练池前 20,000 条候选，其中一条分词后没有可预测普通词元，实际训练 19,999 条。
验证取验证池前 2,000 条，每条按“43 + 原候选索引”固定遮盖，共 4,651 个预测目标。
分词采用本地词表，训练输入最大长度为 64，含 `[CLS]`（序列起始标记）和
`[SEP]`（序列分隔标记）；超长训练样本截断，短样本补齐并用注意力屏蔽排除补齐位置。

对普通词元独立以 15% 概率选择预测目标；如果整条短句没有选中目标，就补选一个。
因此短句的实际选中比例可能高于 15%。被选中位置中：80% 替换为遮盖标记，
10% 随机替换为非特殊词元，10% 保持原样。三类的标签都是原词元编号。
未选中位置标签为 `-100`，不计入交叉熵损失；特殊标记、补齐和未知词元不作预测目标。

标签与输入位置对齐，不做下一字符错位。训练遮盖随训练阶段变化，验证输入和标签固定，
指标按全部有效预测位置加权。保留原词的那部分目标也参与评估，因此总体准确率不能直接
当作“所有目标都完全遮盖”的填空准确率。

项目内独立测试在训练和选模完成后固定：取原验证列表第 2,001～4,000 条，
排除与已用训练、验证以及测试内部的原文和完整分词截断输入重复者，本次 2,000 条全部通过。
测试种子为“2026 + 原完整验证列表零基索引”，得到 4,836 个固定目标。
测试文本没有用于本项目训练或选模；不能保证它们未出现在原始外部预训练语料中。
这是同源语料的项目内保留测试，不是外部跨领域评测。测试不用于继续选择模型或参数。

## 5. 模型与已执行训练配置

模型为双向变换器编码器，加上同位置词表预测头：12 层、每层 12 个注意力头、
隐藏维度 768、前馈中间维度 3,072、词表大小 21,128，约 1.02 亿个参数。
模型位置表支持 512 个位置，但本次课程训练和填空接口使用长度上限 64。
输入词元编号形状为 `[批次, 长度]`，编码结果为 `[批次, 长度, 768]`，
预测头输出为 `[批次, 长度, 21128]`，在被选中位置计算交叉熵。

| 配置 | 第一阶段正式训练 | 第二阶段继续训练 |
| --- | --- | --- |
| 起始权重 | 原始本地预训练权重 | 第一阶段保存模型 |
| 实际样本与轮次 | 19,999 条，一轮 | 相同 19,999 条，再一轮 |
| 每批样本数 / 梯度累积 | 1 / 8 | 1 / 8 |
| 优化器更新次数 | 2,500 | 新增 2,500 |
| 学习率 | 固定 `0.00002` | 峰值 `0.00002`，前 125 次预热，随后线性衰减 |
| 权重衰减 / 梯度范数上限 | `0.01` / `1.0` | `0.01` / `1.0` |
| 数值与显存策略 | BF16（脑浮点十六位格式）混合精度、梯度检查点 | BF16（脑浮点十六位格式）混合精度、梯度检查点 |
| 训练遮盖轮次 | `0` | `1`，更换遮盖与打乱顺序 |
| 验证与选模 | 完整固定验证 | 每 500 次更新完整验证，以验证损失选择最佳模型 |

优化器为 AdamW（带解耦权重衰减的自适应优化器）。第二阶段只接续模型权重，
优化器、学习率调度器和训练随机状态重新初始化，不是完整恢复中断的训练过程。
实际有效批次通常为八条，最后一个累积窗口不足八条，梯度按有效预测位置数归一化。

下面命令仅记录历史过程，便于理解与复现；当前任务不执行训练。

第一阶段使用固定学习率，按当前脚本等价指定该策略：

```powershell
python -I -B .\train_bert_mlm.py --train --lr-scheduler constant --warmup-ratio 0
```

第二阶段历史续训命令：

```powershell
python -I -B .\train_bert_mlm.py --train --model-dir ".\outputs\task04_train_20261105_120133_221669\model"
```

当前训练脚本的默认策略已是预热加线性衰减，因此现在仅运行 `--train` 会从原始权重开始新的
训练实验，不能等同于第一阶段历史命令。硬件、数值库和源码版本变化也可能造成数值差异。

## 7. 填空展示与错误分析的边界

本节的实际填空结果保存在
`outputs/task05_demo_20261105_172341_765469/predictions.json`。
展示句子在运行前固定，包含老师
示例改写和原验证集复核句，不取用独立测试文本，不将五条示例当作额外测试集计算总分。
单遮盖填空与验证时的随机替换、保持原词及多位置同时遮盖不同，不能据此反推完整评估指标。

| 输入中的片段 | 原始预训练模型首选及概率 | 当前模型首选及概率 | 实际解释 |
| --- | --- | --- | --- |
| `中国的首都是北[MASK]。` | 京，98.91% | 京，99.85% | 两份模型都能补为“北京” |
| `我喜欢吃[MASK]果。` | 水，46.74% | 水，86.66% | “水果”与“苹果”均合理；当前“苹”排第二，8.06%，不能只因非“苹”就判错 |
| `他把书放在桌子[MASK]，然后就离开了。` | 上，98.04% | 上，97.97% | 首选相同，概率略降；不强行描述为每例均改善 |
| `看我的新书包好[MASK]吗。` | 看，60.26% | 看，98.85% | 首选相同，“看”的概率更高；“用”也是可能的表达 |
| `如何打开屏蔽的集成显[MASK]` | ？，98.24% | 示，99.33% | 希望恢复“显卡”时两者首选均不符合；当前“卡”排第二，0.59% |

最后一例中的“示”具有很高条件概率，仍未恢复所需的专业搭配，说明置信程度不能代替正确性。
原验证集曾比较第一阶段与当前模型在该句上的退化；此表比较的是原始预训练与当前模型，
比较对象不同，不能把两种对照的首选结果混用。

原验证集错误分析显示：当前模型有 1,201 个原词不匹配，其中 638 个原词仍在前五候选中。
明确替换为遮盖标记的位置准确率约 71.57%，观察到输入保留原词的位置约 99.78%，
说明整体 74.18% 受不同输入状态影响。项目训练中低频词元较难恢复，但常见词元仍贡献约
80.85% 的错误，不能把所有问题归结为低频词。

原文恢复、语句通顺和知识正确性是不同目标。例如“哪个动漫”与“哪部动漫”都可能通顺，
严格原词恢复只接受原标签；专业搭配也可能被更常见的搭配替代。
语料含不完整句子和措辞歧义，未据此改写老师数据或给评分加分。
候选概率是模型对当前上下文的条件概率，没有额外校准，高概率也可能给出不符合目标的词。
本模型用于掩码填空，不能直接当作自回归续写或对话系统。
