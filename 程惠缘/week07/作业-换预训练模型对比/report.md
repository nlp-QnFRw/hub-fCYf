# 第 7 周作业：更换预训练模型，做事件抽取的方法对比

> 数据：DuEE-Fin 派生，13 类事件 / 92 个槽位；评测集 dev_extract **930 句**。
> 指标口径：`common/evaluate_events.py`（全项目唯一），
> 事件级 F1 = 类型 + 触发词 + 全部论元都完全相同才算对。

## 一、实验设计

作业要求「换不同模型 / API / 数据集」。本报告做了**前两条**，共用同一套数据、
同一份标签体系、同一个评测脚本；所有数字跑在**同一批样本**上，用配对检验判断差异是否真实。

| 组 | 变量 | 具体做法 |
|---|---|---|
| ① 换预训练底座 | bert-base → macbert（同尺寸） | 只改 `--bert_path`，其余不动 |
| ② 换解码策略 | CRF → CRF + 非法转移硬约束 | 不重训，只在解码期禁止非法 BIO 转移 |
| ③ 换生成式路线 | 本地 0.6B 微调 / 调 API | LoRA SFT vs deepseek-flash zero/few-shot |

控制变量：数据（DuEE-Fin 派生，13 类 / 92 槽位）、标签体系（149 个 BIO 标签）、
训练配方、评测口径（`common/evaluate_events.py`）全部不变。

| 项目 | 设定 |
|---|---|
| 判别式底座 | bert-base-chinese / chinese-macbert-base（均 102M 参数） |
| 判别式训练 | AdamW，BERT lr=2e-5、头 ×5，warmup 10%，3 epoch，max_len=256，batch 32 |
| 生成式底座 | Qwen3-0.6B（596M，LoRA r=8 只训 0.2% 参数）/ deepseek-flash（API） |
| 评测 | dev_extract 930 句（判别式全量）；跨链路对比用 n=200 同批子集 |
| 配对检验 | McNemar 精确检验（逐句「事件是否完全抽对」） |

## 四、配对检验（事件级，逐句比较）

「独对」= 该方法在这句上把事件完全抽对、对照方法没有。

| 方法 | 对照 | 独对 / 对照独对 | p 值 | 结论 |
|---|---|---|---|---|
| macbert | bert-base | 37 / 43 | 0.576 | 不显著 |
| bert-base+硬约束 | bert-base | 43 / 0 | 2.27e-13 | 显著 |

各方法在 dev 上「事件完全抽对」的句数：bert-base 154、macbert 148、bert-base+硬约束 197（共 930 句）

## 五、结论

### 1. 换同尺寸底座（macbert）：**没有收益**

| 指标 | bert-base | macbert | 差值 |
|---|---|---|---|
| 触发词 F1 | 0.8320 | 0.8009 | −3.11 点 |
| 论元 F1 | 0.5815 | 0.5784 | −0.31 点 |
| 事件级 F1 | 0.1697 | 0.1619 | −0.78 点 |

逐句配对检验：bert-base 独对 **43** 句、macbert 独对 **37** 句，净差 +6 句，
**p = 0.576，不显著**。也就是说：这两个底座在**事件级**上分不出高下。

但**触发词层面是显著的**：bert-base 抽出 755 句、macbert 732 句，配对 42 / 19，
**p = 0.0044**。macbert 的触发词 F1 低了 3.1 个点，是真差异。
事件级差异不显著，是因为事件级被论元错误主导（缺一个论元整条就归零），
把触发词那 3 个点的差异淹没了。

> 对比第 6 周的分类任务：同一个 macbert 在那里是 **+1.38 点且 p=1e-4 显著**。
> 同一个模型、换一个任务，收益不但消失还变成负的 —— 说明**「换底座」不是通用解**，
> 必须看任务瓶颈在哪（这里是解码约束和 schema 对齐，不是底座）。

### 2. 换解码约束（CRF 硬约束）：**极其显著，且零成本**

| 指标 | bert-base | + 硬约束 | 差值 |
|---|---|---|---|
| 触发词 F1 | 0.8320 | 0.8464 | +1.44 点 |
| 论元 F1 | 0.5815 | **0.6566** | **+7.51 点** |
| 事件级 F1 | 0.1697 | **0.2177** | **+4.80 点** |
| 非法 BIO 占比 | 62.5% | **7.4%** | −55 点 |

逐句配对：硬约束独对 **43** 句、bert-base 独对 **0** 句，**p = 2.3e-13**。
**不换模型、不重新训练、耗时 0 秒**，只改解码期的非法转移约束。

### 3. 生成式 vs 判别式（n=200 同批）

本次实跑用的是 `deepseek-flash`（OpenAI 兼容接口，温度默认，max_tokens=512），
**200 条全程 JSON 合法率 100%、解析失败 0**。

- **API few-shot 的论元 F1（0.5832）已经超过两个 BERT 底座**（0.5672 / 0.5768），
  触发词 F1（0.8506）也最高。**单看论元层面，不微调的大模型已经追平甚至反超判别式。**
- **但事件级 F1 只有 0.0759，连 BERT（0.16~0.17）的一半都不到。**
  原因在精确率/召回率的取舍：API 的论元 P=0.635 / R=0.539（偏保守、漏抽多），
  BERT 是 P=0.526 / R=0.615（偏激进）。**事件级要求「一个不多、一个不少」**，
  两种偏差都会让整条事件归零，于是差距被放大成 2 倍以上。
- **LoRA 微调过的 0.6B 模型是全场最强**：论元 **0.7266**、事件级 **0.2600**，
  比 BERT+CRF（0.5672 / 0.1748）高 **+8.5 个事件点（相对 +49%）**，
  也高于同批的「BERT + 解码硬约束」（0.6418 / 0.2268，+3.3 个事件点）。
  训练代价：**38.6 分钟、峰值显存 3.05 GiB、adapter 仅 9 MB**（对比全量微调 68 分钟 / 5.58 GiB）。
  所以不是「LLM 不行」，而是「**不微调的 LLM 干不过为这个 schema 特训过的小模型**」。
- 生成式的真正优势在**标注数据为零时的冷启动**（零样本就有 0.5516 论元 F1，
  和训好的 BERT 只差 1.6 个点），以及换 schema 不用重训。
- **三条路线的取舍**：换 BERT 底座 ≈ 0 收益；调 API ≈ 论元追平但事件级崩；
  **微调小模型 = 全面最优**，代价是要有标注数据和 40 分钟 GPU。

> 成本参考（本次实测）：zero-shot 200 条用 189,135 tokens、0.885s/条；
> few-shot 200 条用 310,363 tokens、0.917s/条。按 DeepSeek 定价约几毛钱，
> 但 few-shot 的 prompt 因为要塞示例，token 量是 zero-shot 的 **1.6 倍**。

### 4. 一句话总结

> 在**封闭 schema 的抽取任务**上，瓶颈不在「底座多聪明」，而在
> **「解码器有没有被约束住」** 和 **「输出能不能严格落进 92 个槽位」**。
> 换更大/更好的预训练模型收益接近 0；加一条非法转移约束就是 +4.8 个事件点。

## 六、局限（必须一起读）

1. **只有 1 个种子。** McNemar 检验比较的是**这两个具体训练实例**，
   它回答「这两个模型谁更好」，**不能**推广成「macbert 这个预训练方法更差」。
   第 6 周实测过：同一个模型换种子重跑，500 条上能差 2.2 个点。要下方法级结论至少需要 3 个种子。
2. **训练时间不可比。** 两个 run 的配置已逐项核对完全一致
   （`crf / max_len=256 / batch=32 / 3 epoch / lr=2e-5 / seed=42`，参数量都是 102,404,728），
   但耗时分别是 1208s 和 2742s —— 这是**不同次运行/不同机器负载**造成的，
   **不能写成「macbert 训练更快」**。
3. **生成式两条线只跑了 n=200 子集**（全量 930 句跑 LoRA 推理要额外 20 分钟）。
   且 API 用的模型（`deepseek-flash`）与课件记录的（`deepseek-v4-flash`）不是同一版本，
   本次数字整体比课件高 2~4 个点，两套数**不要混着引用**。
4. **事件级 F1 的绝对数值很低（0.16 ~ 0.26）**，这不是模型差，是口径严：
   13 类 × 92 槽位，一个论元错整条就 0。报告里必须同时给论元 F1，只看事件级会误判。
5. **只换了「模型」和「API」，没有换数据集** —— 换数据集需要改 schema（92 个槽位全变），
   超出本次时间范围，可作为后续方向。

## 七、可与下周对比的观察

- 抽取任务的事件级 F1 天花板很低（0.17~0.22），因为它是「全对才算对」的严格口径；
  报告里要用论元 F1 和事件级 F1 一起说，只看一个会误判。
- 非法 BIO 序列占比是一个容易被忽略的指标：bert-base 有 62%，加硬约束后降到 7%。
