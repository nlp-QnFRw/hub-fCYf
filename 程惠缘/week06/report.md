# 第 6 周作业：更换预训练模型，做分类任务的对比实验

> 评测口径：CLUE TNEWS 重映射后的 15 分类；去重后干净验证集 **8,901 条**（剔除与训练集重复的 1099 条），seed=42 固定同一批样本。
> 所有方法跑在同一批样本上，指标用 `common/metrics.py` 统一计算。

## 一、实验设计

**变量**：只换预训练的底座（BERT 权重）。数据、标签口径、训练配方、评测指标全部不动。

| 项目 | 设定 |
|---|---|
| 底座 | bert-base-chinese / chinese-macbert-base / chinese-roberta-wwm-ext-large |
| 参数量 | 102M / 102M / 326M |
| 训练配方 | AdamW，BERT lr=2e-5、分类头 ×5，warmup 10%，类别加权，3 epoch |
| 有效 batch | 统一 64（large 用 batch 16 × 梯度累积 4） |
| 评测集 | 8,901 条干净验证样本（同一批，seed=42） |
| 显著性 | McNemar 精确检验（同一批样本的配对比较） |

> 为什么不用课件默认的 500 条：500 条上 acc≈0.55 的标准误是 2.2%，
> 95% 置信区间 ±4.4 个点 —— 「换模型涨 2 个点」和「同模型换种子重跑」一样大。
> 本实验用全部 8,901 条，标准误降到 0.53%。

## 五、结论

数字都能在上面几张表里找到；可以按自己的话改。

1. **同尺寸换预训练目标（bert-base → macbert）：稳赚。** 参数量、训练时间完全一样，
   两个种子分别 +1.38 / +1.00 个点，McNemar p = 1.0e-4 / 9.4e-3，都显著。
   ECE 基本持平（0.128 vs 0.126），没有付出任何额外代价。
2. **换大 3 倍（roberta-large）：收益有限、代价高。** 比 bert-base 高 +2.46 个点（p≈0），
   但训练从 14 分钟涨到 69 分钟（3.8 倍），而且 **ECE 从约 0.13 升到 0.1505** ——
   置信度更不可信，做阈值路由时反而更难用。
3. **课件「判别式比 TF-IDF 强 5~7 个点」这个结论，主要来自 500 条抽样。**
   同一条 TF-IDF 流水线，评测集从 500 条换成 8,901 条，Macro-F1 从 0.4721 升到 0.5087
   —— 仅抽样就差了 3.7 个点，等于把 BERT 的优势虚高了同样的幅度。
   换成全量评测后，**bert-base 相对 TF-IDF 只剩约 +1 个点，而且处在显著性边缘**
   （两个种子 p=0.065 / 0.043，一个过一个不过，结论不稳健）；
   **只有升级到 macbert / roberta-large，这个优势才稳定成立**（+2.1 ~ +3.4 点，p<1e-4）。
4. **大模型不是全面更好。** roberta-large 在「国际/科技/娱乐」大涨 8~14 个点，
   却在「军事/旅游/财经」倒退 3~12 个点，净收益为正但分布很不均匀；
   相比之下 macbert 几乎是单调改善（只掉 0.7~1.3 个点）。

## 六、局限

- **种子数不齐**：bert-base / macbert 各 2 个种子，roberta-large 只有 1 个（单次要 69 分钟）。
- **只换了 BERT 家族**：未复跑 LLM 三条路线（本地零样本 / LoRA / API），
  它们是生成式方法，换底座的结论未必能迁移。
- **没做早停**：统一固定 3 epoch，可能不是每个底座的最优轮数。
- **单机单卡**：batch 与显存受限，large 用了梯度累积，等效 batch 一致但不是同一实现。

## 七、可复现

```bash
# 三个底座，各 3 epoch，评测全部 8,901 条干净样本
python run_compare.py --models bert-base,macbert,roberta-large --seeds 42 --epochs 3
# 补第二个种子
python run_compare.py --models bert-base,macbert --seeds 43 --epochs 3
# 汇总成这份报告
python make_report.py
```
